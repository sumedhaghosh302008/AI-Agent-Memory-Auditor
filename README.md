# AI Agent Memory Auditor 🤖

**Detecting and Catching Hallucinated Agent Memories**

## 📌 Overview
Built as a team project for the **Devnovate Hackathon 2026 (Bengaluru by Microsoft)**, this project explores how AI agents fabricate or distort past context—and provides an interface to inspect, verify, and catch memory inconsistencies in real time using validation gates.

## 🎥 Demo Video
* **YouTube Walkthrough:** [Watch the Project Demo](https://youtu.be/lwwv5VxA1BQ?si=6FWJgDGObZDywF0y)

## ✨ Key Features
* **Memory Consistency Checks:** Flags when an AI agent invents or alters past interactions.
* **Validation Gates:** Prevents raw, unverified logs from cluttering agent context windows.
* **Interactive Inspection:** Lets users test prompts and verify stored memory logs easily.

## 🛠️ Built With
* AI-Assisted Prototyping (Text-to-Code Workflow)
* Web Technologies (HTML / CSS / JavaScript)
